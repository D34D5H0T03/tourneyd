Engineered from the socket up.

I'm Abdul Basit, a CSE undergrad based in Bangladesh focused on systems programming, vulnerability research, and exploit development. My long-term objective is advancing program analysis and fuzzing at the lowest levels of computation.

What began as an exploration of the TCP/IP stack inspired by the theoretical foundations in Computer Networking: A Top-Down Approach has evolved into tourneyd. It is a custom, bare-metal C web server built entirely without external frameworks.

This infrastructure serves as a high-performance staging ground to host Capture The Flag competitions, orchestrate algorithmic contests, and permanently archive offensive security writeups.

> Architecture: Multi-process Forking Model
> Request Dispatch: O(N) Read-Only Prefix Matching
> Document Root: Secured via POSIX realpath()
> Target: Non-blocking TLS + epoll
