System architecture.

tourneyd is a zero-framework, monolithic HTTP/1.1 web server written in C. Every layer—from TCP socket binding and incremental state-machine parsing to canonical path resolution—is engineered manually to maintain strict control over memory, file descriptors, and security boundaries.

> Dependency Flow: main → core → concurrency → connections → http → app → db
> Isolation Rule: Protocol parsing (http/) is 100% decoupled from socket I/O (net/, connections/).

// 01_Core_Subsystems

[NET & CONCURRENCY] src/net/

Socket & Process Layer

IPv4/IPv6 dual-stack listener via getaddrinfo with SO_REUSEADDR. Pluggable compile-time concurrency models (fork_model and serial_model) with non-blocking SIGCHLD zombie reaping (WNOHANG) and EINTR-resilient read/write loops.

MODEL: FORK_PER_CONN FD_SAFE: YES
[HTTP ENGINE] src/http/

State-Machine Parser

Pure, I/O-free incremental parser (PARSE_REQ_LINE → PARSE_HEADERS → PARSE_BODY). Enforces strict compile-time bounds (4KB lines, 1MB bodies, 50 headers) and pairs with a serializer that strips reserved framing overrides and blocks CRLF header injection.

PROTOCOL: HTTP/1.0 & 1.1 HEAP_ISOLATED: YES
[DISPATCHER] src/http/router.c

Read-Only Route Table

Populated once prior to fork() or thread creation. Supports exact matches and longest-prefix scoring, automatic HEAD-to-GET aliasing, fallback delegation, and bitmask-calculated 405 Method Not Allowed responses with dynamic Allow headers.

MAX_ROUTES: 64 LOCK_FREE: YES
[STATIC DELIVERY] src/app/static_files.c

Hardened File Server

Decodes percent-encoded paths upfront while rejecting %00 null-byte injections. Defeats directory traversal and symlink escapes via kernel-resolved realpath() containment checks, O_CLOEXEC descriptors, and fstat() TOCTOU verification.

MAX_FILE: 8 MB NOSNIFF: ENFORCED

// 02_Defensive_Engineering

[01] Directory Traversal Quarantine — Rejects /. segments and verifies realpath() prefixes against the canonical doc_root before opening descriptors. static_files.c
[02] TOCTOU & Device File Prevention — Inspects open file descriptors via fstat() and enforces S_ISREG to block directory or device reads. static_files.c
[03] Null-Byte & CRLF Injection Defense — Blocks %00 in URL decoding and rejects \r/\n in custom response headers. url.c / response.c
[04] Stack & Heap Exhaustion Caps — Allocates 30KB request/response structs on the heap per connection and caps static payloads at 8MB. http_connection.c
